ORBITBREAK is a neon radial arcade shooter: a guardian rides a circular orbit around a fragile core, firing bolts that ricochets off the walls at invaders spiralling inward. Catch drops to heal, triple your shot or slow time; survive the waves and chase a high score.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
